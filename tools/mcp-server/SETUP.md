# עריכת שאלונים עם קלוד — התקנה ושימוש

הכלי הזה מחבר את קלוד (Claude Desktop או Claude Code) למערכת השאלונים, כך
שאפשר לבקש בשפה חופשית: "תוסיף פרסונה לזוגות צעירים", "תגדיר ניסוי מחיר
79/149/249", "כמה מסכים יש בשאלון?" — וקלוד עורך את **הטיוטה** בשבילכם.

מה הוא **לא** יכול לעשות, בכוונה: לפרסם גרסה, למחוק שאלון או להעביר לארכיון.
את זה עושים רק בקונסולה ב-`/admin`, אחרי שעברתם על הטיוטה בעיניים.

---

## התקנה (פעם אחת)

צריך: [Node.js](https://nodejs.org) גרסה 20 ומעלה, ועותק של הריפו.

```bash
git clone <repo-url> mortgage-survey
cd mortgage-survey
npm install
npm run mcp:build
```

הפקודה האחרונה יוצרת קובץ אחד: `tools/mcp-server/dist/index.mjs`.

### צעד חד-פעמי של מנהל המערכת (Supabase)

ההתחברות נפתחת בדפדפן וחוזרת לכתובת מקומית. את הכתובת הזאת חייבים לאשר
מראש בדשבורד Supabase — **Authentication → URL Configuration → Redirect URLs**,
להוסיף:

```
http://127.0.0.1:43117/callback
```

⚠️ בלי זה ההתחברות תיכשל בשקט: Supabase מתעלם מכתובת redirect שלא ברשימה.
זה צעד אחד, פעם אחת, לכל הצוות.

### חיבור ל-Claude Desktop

לפתוח את קובץ ההגדרות (Settings → Developer → Edit Config), ולהוסיף תחת
`mcpServers` (להחליף את הנתיבים והערכים האמיתיים):

```json
{
  "mcpServers": {
    "mortgage-survey": {
      "command": "node",
      "args": ["C:/path/to/mortgage-survey/tools/mcp-server/dist/index.mjs"],
      "env": {
        "SURVEY_API_URL": "https://<the-site>.netlify.app",
        "SURVEY_SUPABASE_URL": "https://<project>.supabase.co",
        "SURVEY_SUPABASE_ANON_KEY": "<the anon key>"
      }
    }
  }
}
```

- `SURVEY_API_URL` — כתובת האתר בפרודקשן.
- `SURVEY_SUPABASE_URL` וה-anon key — מופיעים בדשבורד Supabase תחת
  Project Settings → API. ה-anon key **ציבורי בהגדרתו** (הוא כבר נמצא בדפדפן
  של כל מי שפותח את הקונסולה) — הוא לא סוד. לעולם לא שמים כאן את
  ה-service_role key.

לסגור ולפתוח את Claude Desktop. אמור להופיע השרת "mortgage-survey" ברשימת
הכלים.

### חיבור ל-Claude Code

מתוך תיקיית הריפו:

```bash
claude mcp add mortgage-survey \
  --env SURVEY_API_URL=https://<the-site>.netlify.app \
  --env SURVEY_SUPABASE_URL=https://<project>.supabase.co \
  --env SURVEY_SUPABASE_ANON_KEY=<the anon key> \
  -- node tools/mcp-server/dist/index.mjs
```

### מפתחים: הרצה מול הסביבה המקומית

בלי שום משתני סביבה, השרת פונה כברירת מחדל ל-`netlify dev` המקומי
(`http://localhost:8888`) ולסטאק Supabase המקומי (`npx supabase start`) עם
מפתחות הדמו הציבוריים — אפשר לבדוק הכול בלי לגעת בענן.

כתובת ה-callback של ההתחברות כבר מוגדרת ב-`supabase/config.toml` לסטאק
המקומי. כניסת Google מקומית דורשת את ההגדרה החד-פעמית שמתוארת ב-README
(`SUPABASE_AUTH_GOOGLE_CLIENT_ID/SECRET` ב-`.env` + הפעלה מחדש של הסטאק).

## התחברות

בפעם הראשונה שקלוד ניגש לשאלונים, ייפתח דפדפן עם מסך ההתחברות של Google.
נכנסים עם **חשבון first-edea.com** (אותו חשבון כמו בקונסולה), ורואים
"ההתחברות הצליחה". מכאן הכניסה נשמרת ומתרעננת לבד — לא תצטרכו את זה שוב
אלא אם ההרשאה פגה או בוטלה.

אין סיסמאות משותפות ואין מפתח קסם: כל אחד נכנס עם החשבון של עצמו, וכל
שינוי נרשם על שמו ביומן.

## איך עובדים עם זה

הזרימה שקלוד מונחה לעבוד בה:

1. קלוד טוען את הטיוטה הנוכחית ומציג תמונת מצב.
2. אתם מבקשים שינוי; אם משהו לא חד-משמעי — קלוד ישאל.
3. קלוד מציג **מה בדיוק ישתנה** (בעברית, כמו בקונסולה) ומחכה לאישור שלכם.
4. רק אחרי אישור מפורש השינוי נשמר — **לטיוטה בלבד**.
5. קלוד מריץ סימולציה של מסלולי המשיבים שנגעו בשינוי ומראה שהכול מתנהג.
6. את הפרסום עושים אתם, בקונסולה, אחרי שעברתם על הטיוטה.

## הודעות שכדאי להכיר

**"הטיוטה השתנתה מאז שנטענה"** — מישהו (אולי אתם, בטאב אחר) שמר בקונסולה
בזמן שקלוד עבד. שום דבר לא נדרס: קלוד יטען את המצב העדכני ויציע את השינוי
מחדש מעליו. אם עבדתם בקונסולה במקביל — סיימו שם קודם.

**"קודי האנליזה נעולים"** — השאלון כבר פורסם לפחות פעם אחת, ולכן אי אפשר
לשנות שם של סימון, של הגרלה או של ערך שהגרסה שפורסמה משתמשת בהם: תשובות
שכבר נאספו רשומות תחת הקודים האלה, ושינוי שם היה מנתק אותן מהנתונים.
אפשר תמיד **להוסיף** קודים חדשים. אם באמת צריך שם אחר — זו החלטה מחקרית,
דברו עם מי שמנהל את המחקר.

**"חריגה ממכסת הבקשות"** — יש תקרה שעתית לכמות השינויים (הגנה מפני לולאה
משתוללת). ההודעה אומרת בדיוק כמה זמן לחכות. השינוי שלכם לא הלך לאיבוד —
בקשו מקלוד לנסות שוב אחרי ההמתנה.

**"ההתחברות פגה"** — ייפתח דפדפן להתחברות מחדש. אם החשבון שלכם הוסר
מהמערכת, ההתחברות תיחסם — דברו עם מנהל המערכת.

## פתרון תקלות

- **"לא ניתן לפתוח את פורט ההתחברות"** — כנראה רץ עוד עותק של השרת (למשל
  Claude Desktop ו-Claude Code יחד). לסגור אחד מהם, או לקבוע פורט אחר עם
  `SURVEY_MCP_LOGIN_PORT` (ולהוסיף גם אותו ל-Redirect URLs בדשבורד).
- **הדפדפן לא נפתח בהתחברות** — ההודעה בשיחה כוללת את הקישור; להעתיק
  ולפתוח ידנית.
- **אחרי `git pull`** — להריץ שוב `npm install && npm run mcp:build`.
- ההתחברות שמורה ב-`~/.mortgage-survey-mcp/auth.json`. מחיקת הקובץ =
  התנתקות מלאה (ההתחברות הבאה תיפתח בדפדפן).
